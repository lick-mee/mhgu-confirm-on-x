Confirm on X - menus confirm with the bottom button on MHGU Recomp

Menus confirm with the bottom face button (PlayStation Cross, Xbox A) and go back with the right one
(Circle, Xbox B). Everything else plays like the original game: the bottom button rolls, the right one
talks, gathers, carves and opens boxes.

Install
  Put this folder (confirm-on-x) in the recomp's mods folder and start the game.

Options
  Press Insert in game and open "Confirm on X" to switch it off, or to try the optional modes.

Uninstall: delete this folder.
